Every morning the daily search reads your CV and this profile to pick positions for you. Edit them here any time; changes apply from the next search.

1. Your CV

Only the text is saved (not the PDF), in data/cv.md of your public GitHub repository, so anyone can view it. Check the text and fix anything that came out wrong.

2. What to search for

Your research topics, keywords, countries, position types and anything to exclude. Lines starting with - are list items.

3. Permission to save
✅ This browser can save to GitHub.

The site needs a GitHub token to save. Do this once per device:

  1. Open GitHub → new fine-grained token.
  2. Name it "Careerly", pick an expiration, and under Repository access choose Only select repositories → Careerly.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it and paste it here. It's kept only in this browser.
